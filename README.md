# Executive Insurance Analytics Dashboard (Power BI)

This repository contains a Power BI dashboard built to provide senior leadership with a unified, real‑time view of key insurance KPIs across Claims, Premiums, Loss Ratios, and Portfolio Mix. The solution standardises KPI definitions, improves reporting efficiency, and enables drill‑down analysis for strategic decision‑making.

---

## Overview

The dashboard was developed to address fragmented reporting across underwriting, claims, and finance. Manual Excel‑based processes created inconsistent KPIs and limited visibility. This solution consolidates data into a single, interactive Power BI experience.

---

## Key Features

- Executive‑level KPI summary (Claims, Premiums, Loss Ratio, Exposure)
- Drill‑downs by Product, Region, and Channel
- Trend analysis and variance insights
- Standardised KPI definitions across departments
- Clean star‑schema data model for performance
- Advanced DAX measures including time intelligence (MTD, QTD, YTD)

---

## Solution Components

**Data Model**
- DIM Claims, Fact Policy, and other supporting dimension tables  
- Optimised relationships and incremental refresh  
- Consistent KPI logic across visuals  

**DAX Measures**
- Claims Ratio  
- Earned Premium  
- Exposure  
- Loss Ratio  
- Time intelligence metrics  

**Dashboard Design**
- Consulting‑grade layout  
- KPI cards, trends, drill‑through pages  
- Hierarchies for multi‑level exploration  

---

## Business Impact

- Reduced manual reporting effort  
- Eliminated inconsistent KPI definitions  
- Faster identification of loss‑making segments  
- Improved executive visibility and decision‑making  
- Established a single source of truth for performance reviews
